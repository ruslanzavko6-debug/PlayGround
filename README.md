# PlayGround

## ⛏️ VOXELCRAFT — пісочниця у кубах

Невеликий браузерний клон Minecraft, який працює без збірки та без зовнішніх
залежностей: процедурний острів 192 × 192, 12 чанків у кожному напрямку, гори,
ліси, пляжі, кактуси та океан навколо.

- **Копай і будуй** — ЛКМ ламає блок із прогресом за твердістю, ПКМ ставить
  вибраний блок; є виділення цілі, частинки та звук.
- **Живий світ** — день і ніч, зорі, сонце/місяць, вода з хвилями, туман,
  процедурні хмари, вода під водою та нічне освітлення.
- **Гравець** — ходьба, біг, стрибок, плавання, політ (`F`), колізії, бobbing
  камери та рука з блоком у першій особі.
- **Збереження** — зміни блоків, позиція гравця та час доби зберігаються в
  `localStorage`; кнопка «Новий світ» створює інший острів за сідом.
- **Телефони й планшети** — адаптивний HUD, віртуальний джойстик, кнопки
  копати/ставити та свайп-огляд без конфлікту з жестами браузера.
- **100% процедурно** — текстури, звуки, небо й рельєф генеруються кодом;
  Three.js покладено локально у `vendor/`, тож гра працює офлайн.

Запуск: відкрийте `index.html` через будь-який статичний HTTP-сервер
(наприклад, `python3 -m http.server 3002`), або скористайтеся `start.sh`.

Керування: `WASD` — рух, `Space` — стрибок, `Shift` — біг, `F` — політ,
`E` — інвентар, `Esc` — пауза, `1–9` — вибір блока, ЛКМ/ПКМ — копати/ставити.
