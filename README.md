## 🎮 CS:GO 1.6

A dependency-free, browser-based FPS inspired by Counter-Strike 1.6 and the Dust II map.
Everything is procedural: raycast 3D renderer, textures, sprites, weapon models and WebAudio
sound effects — no external assets or network requests.

### Run

Open `index.html` directly, or serve the folder:

```bash
python3 -m http.server 3002
```

### Controls

| Action | Desktop | Mobile |
| --- | --- | --- |
| Move | `WASD` | left joystick |
| Look | mouse (drag if pointer lock is unavailable) | drag on the world |
| Fire | left mouse button | `ОГОНЬ` |
| Reload | `R` | `⟳` |
| Switch weapon | `1` / `2` / `3` or `Q` | `⇄` |
| Pause | `Esc` | `II` |

Clear all terrorists to win the round. Headshots deal bonus damage. Earn cash for kills and
round wins, then survive as long as possible — difficulty rises every round.
